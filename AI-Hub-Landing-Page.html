# 1. Install official standard library
from openai import OpenAI

# 2. Point base_url to AI Hub Gateway
client = OpenAI(
  api_key="aih_live_sec_9941a87b...",
  base_url="https://api.aihub.dev/v1"
)

# 3. Request any model with failover routing
response = client.chat.completions.create(
  model="deepseek-v3",
  messages=[
    {"role": "user", "content": "Synthesize Q4 financial vector index"}
  ],
  extra_headers={
    "X-AIHub-Fallback": "claude-3-5-sonnet,gpt-4o"
  }
)

print(response.choices[0].message.content)

KNOWLEDGE BASE & ARCHITECTURE FAQ

คำถามที่พบบ่อยเกี่ยวกับการใช้งาน AI Hub

ตอบข้อสงสัยด้านเทคนิค ค่าบริการ ระบบ Fallback และการเชื่อมต่อเอกสาร Documentation

ระบบคิดค่า Token ตามราคาจริงที่ Provider (OpenAI, Anthropic, Google, DeepSeek) เรียกเก็บ (Pass-through rate) โดยไม่มีการ Markup แอบแฝงบนแพ็กเกจพื้นฐาน ในส่วนของแพ็กเกจ Growth หรือ Enterprise จะมีค่าธรรมเนียมโครงสร้างระบบ Routing & Failover SLA เพิ่มเติมตามที่ระบุไว้ชัดเจน
เราซิงก์ข้อมูลและเพิ่มโมเดลใหม่เข้าสู่ระบบภายในไม่เกิน 2 ชั่วโมงหลังจากที่ค่ายต้นทางประกาศเปิดตัว API (เช่น Claude 3.5 Sonnet, GPT-4o, DeepSeek-V3, FLUX.1) คุณสามารถเรียกใช้โมเดลใหม่ได้ทันทีโดยไม่ต้องอัปเดตไลบรารีบนโค้ดของคุณ
คุณสามารถระบุ Fallback chain ใน Header เช่น X-AIHub-Fallback: claude-3-5-sonnet, gpt-4o หาก Provider ตัวแรกตอบกลับเป็น HTTP 429, 500 หรือ Timeout เกินกว่าค่าที่กำหนด เกตเวย์จะสลับคำขอไปยัง Provider ลำดับถัดไปทันที ช่วยรับประกันว่าผู้ใช้งานปลายทางของคุณจะไม่ได้รับ Error
ใช่ เอกสารคู่มือทางเทคนิค (Documentation), รายการ Endpoint ทั้งหมด, โค้ดตัวอย่าง Python/TypeScript, และรายงาน Benchmark ของโมเดล เปิดให้อ่านแบบสาธารณะ 100% โดยไม่มี Paywall หรือการบังคับเข้าสู่ระบบตามกฎ Business Requirement BR-002
แก้ไขเพียง 2 จุดเท่านั้น: (1) เปลี่ยน base_url เป็น https://api.aihub.dev/v1 และ (2) นำ API Key ที่ได้จาก AI Hub Console มาใส่แทน ไม่ต้องแก้ Request format หรือ Response parser ใดๆ เลย
